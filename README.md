# Om Patel — Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

**Live:** https://ompatel179.github.io

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Edit

- Content: `index.html` (each project is an `<article class="card">`)
- Colors and layout: `style.css` (theme tokens at the top)
- Resumes: `resume/`

Pushing to `main` redeploys the site automatically.
